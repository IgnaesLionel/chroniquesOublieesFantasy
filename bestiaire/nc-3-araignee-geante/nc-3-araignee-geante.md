# NC 3 Araignée Géante

- Catégorie : Monstres/Créatures
- NC : 3
- Source Notion : https://silver-pen-32f.notion.site/NC-3-Araign-e-G-ante-2eed3d06b0988149a4bfec287978d1d9
- Description :
  - Les araignées géantes (arthropodes) sont des monstres terrifiants : rapides, puissants et capables de survivre aux pires blessures. On trouve les araignées géantes dans les forêts sombres et reculées, mais aussi dans les souterrains, surtout les plus grosses d'entre elles. Il en existe de nombreuses variantes, mais celle que nous vous proposons ici fait le poids d'un humain, elle est donc moins haute mais occupe un espace de presque 2 m de diamètre.
  - Tir à distance (mention Notion).

## Profil — Araignée géante

- État : Vivante — Taille : Moyenne — NC 3
- Caractéristiques : AGI +4 (*) / CON +3 (*) / FOR +3 (*) / PER +2 / CHA -4 / INT -4 / VOL +0
- Initiative 12 — Défense 17 — RD 0
- Vigueur 30 — DM Temp. 0 — Déplacement 10 m — États : —
- Attaques : Mandibules +6, DM 2d4+4 (Attaque +6, Dommages 2d4+4)
- Actions : Araignée chasseuse - Si surprise ; Poison mortel ; Soutenir (L) ; Toile (L)
- Propriétés : VERMINE — Une araignée géante peut encore agir un round complet lorsqu'elle atteint 0 PV. Une araignée se déplace de 15 m par action de mouvement. VARIANTES : choisissez un type de poison et soit Toile (L), soit Araignée chasseuse.

## Capacités

### Poison mortel (Capacité)

Le poison inflige 2d6 DM supplémentaires à la victime à chaque attaque. Si la victime réussit un test de CON de la difficulté indiquée, elle subit seulement la moitié des DM.

### Toile (Capacité)

Sur un test d'attaque réussi (portée 3 m), l'araignée emprisonne sa cible dans une toile gluante et solide. Elle est immobilisée ; se libérer nécessite l'usage d'une action limitée et il faut réussir un test de FOR difficulté 12.

### Araignée chasseuse (Capacité, origine : Livre des règles p275)

Au premier round de combat, si l'environnement permet de se dissimuler, la cible doit faire un test de PER difficulté 19 ou être surprise. Si elle attaque avec succès une cible surprise, la créature inflige +1d4 DM et toute créature dont la FOR est inférieure à la sienne est renversée. La créature obtient un bonus de +5 à tous les tests de discrétion.
