## Profil — Sigméus, le nécromant (bloc ancienne édition, tel qu'affiché)

Sous une robe sombre d'un autre âge, une créature squelettique vous contemple de toute sa hauteur.

- FOR +3 / DEX +3 / CON +5 / INT +3 / SAG +0 / CHA -4
- Initiative 16 — DEF 22 — PV 32
- Main spectrale +10, DM 1d6+5
- Effroi : lors du premier tour de combat, tous les adversaires du nécromant doivent effectuer un test de SAG difficulté 10. Ceux qui échouent ne peuvent pas l'attaquer pendant 1d4 tours.
- Main spectrale (L) : une main spectrale attaque à distance.
- Baiser du vampire (L) : le nécromant effectue une attaque de Main spectrale contre un adversaire au contact. S'il réussit, il lui inflige 2d6 de DM et se soigne 2d6 PV perdus !
