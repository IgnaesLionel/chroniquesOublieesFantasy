# NC 1 Zombie Humain

- Catégorie : Monstres/Créatures
- NC : 1
- Source Notion : https://silver-pen-32f.notion.site/NC-1-Zombie-Humain-2eed3d06b09881ef8f3ac68d964b54ac
- Source DRS : https://drs.chroniques-oubliees.fr/fantasy/creatures
- Vérification DRS (11/10/2026) : conforme (cycle zombie + gabarit).
  - Variante DRS verrouillée (compte BBE) : non vérifiable.
- Description :
  - Un zombie est un mort-vivant animé à partir d'un cadavre récent. Les chairs peuvent être à un stade plus ou moins avancé de putréfaction, mais le corps doit être globalement complet. Le zombie est une créature stupide qui suit les ordres de son créateur ou erre sans but et attaque toute créature vivante à portée.
  - Pour obtenir un zombie, vous pouvez partir de n'importe quelle créature, qui acquiert le type non-vivante (ce qui inclut une RD de 5 contre le froid). Ajoutez les capacités suivantes.
