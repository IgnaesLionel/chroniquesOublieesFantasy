# Audit des capacités et des sorts

Document généré depuis le référentiel et les tables du moteur. Il recense **toutes** les capacités de profil, les traits de peuple / Voie du mage et les sorts, avec leur mode de résolution actuel.

## Légende

| Statut | Signification |
|---|---|
| **Effet automatique** | Effet/état posé par le moteur (catalogue ou effet libre nommé). |
| **Action spéciale** | Action dédiée du panneau Capacités (soin, purge, invocation, lien...). |
| **Dégâts automatiques** | Dégâts lancés et appliqués sans jet d'attaque. |
| **Attaque (panneau Attaque)** | Talent résolu par le sélecteur / les cases Coup spécial. |
| **Guidé (pop-up MJ)** | Action lançable, question au MJ et journalisation ; la règle complexe reste arbitrée. |
| **Passif moteur** | Bonus chiffré intégré aux valeurs dérivées (détection indicative dans le code). |
| **Passif à préciser** | Texte et bonus affichés sur la fiche, mais pas de chiffrage dédié dans le moteur. |
| **Sort lié** | La capacité ouvre un sort : voir la section Sorts. |

> « Passif moteur » est une détection indicative par présence du nom exact dans les fichiers de règles. Un passif peut être partiellement automatisé (ex. un bonus conditionnel calculé seulement dans certains cas).

### Points de vigilance connus

- **Rage / Furie du berserk** : l'activation pose les modificateurs d'attaque/DEF ; le bonus de DM (+1d4° / +2d4°) se choisit dans le sélecteur de talent d'attaque à chaque attaque concernée.
- **Armure de pierre** : la RD 5 est appliquée tant que l'effet dure ; le plafond « niveau × 3 DM absorbés » n'est pas suivi automatiquement.
- **Délivrance** : la purge des états est guidée par la pop-up MJ ; les effets non permanents ne sont pas retirés automatiquement.
- **Déphasage** : la division par 2 des DM physiques n'est pas automatisée ; le MJ l'applique après le jet.
- **Invisibilité, Vol, Forme gazeuse, Éthérée, Téléportation, Mur de mana, Sommeil, Peur, Domination, Confusion** : effets narratifs ou partiels, cible/portée/fin d'effet précisés par la pop-up.
- **Talents de zone** (Attaque tourbillon, Fureur du dragon, etc.) : le panneau Capacités ne cible qu'une créature à la fois ; le MJ répète l'usage pour les autres cibles.
- **Talents de peuple artistiques / érudition / survie** : les bonus sont affichés sur la fiche et rappelés au MJ, mais ne sont pas tous injectés dans les jets courants (compétences non modélisées).
- **Talents d'attaque non couverts** : le sélecteur générique du panneau Attaque les résout avec un dé bonus et/ou des DM bonus ; les effets de renversement/étourdissement restent au MJ.
